Potato Today · 오늘의 감자

감자 표정으로 기분을 고르고, 남기고 싶은 순간만 적어보세요. 모든 칸을 채우거나 매일 쓸 필요는 없어요.

기록은 어떻게 저장하나요?

입력한 내용은 기기에 자동 저장돼요. ‘오늘은 여기까지’를 누르면 읽기 화면으로 바뀌어요. ‘오늘’에서 ‘수정하기’를 눌러 오늘의 내용을 고칠 수 있어요. 전날의 기록은 현지 시각 새벽 5시 전까지 수정할 수 있어요. 그보다 오래된 기록은 읽기 전용이에요.

백업은 어떻게 하나요?

  1. 설정 → 데이터 백업 내보내기를 눌러 일기와 사진이 함께 담긴 ZIP 파일을 파일 앱 등 원하는 곳에 보관해 주세요.
  2. 다른 기기에서는 설정 → 데이터 백업 가져오기에서 저장한 ZIP 파일 (또는 기존 JSON 백업)을 골라 주세요.

이미 있는 날짜는 그대로 두고 없는 날짜만 가져와요. 백업 파일은 암호화되지 않으므로 안전한 곳에 보관해 주세요. 앱 삭제나 기기 변경 전에 백업을 권장해요.

사진도 남길 수 있나요?

기록 화면에서 하루 한 장을 선택할 수 있어요. 사진은 기기에만 저장돼요.

밤 11시 알림이 오지 않아요.

설정 → 알림 설정에서 알림을 켜고 iPhone의 알림 권한을 허용해 주세요. 기기의 현지 시각 밤 11시에 조용한 알림을 예약해요. iPhone의 집중 모드나 알림 요약 설정에 따라 표시가 늦어질 수 있어요.

기록을 복구할 수 있나요?

개발자 서버에는 기록을 보관하지 않아 개발자가 복구할 수 없어요. 직접 내보낸 백업 파일이나 운영체제의 기기 백업이 있다면 해당 복원 방법을 확인해 주세요.

문의하기

앱의 설정 → 버그 신고·기능 요청에서 바로 보낼 수 있어요. 회신 이메일은 선택이며, 개인적인 일기나 사진은 자동 첨부되지 않아요.
