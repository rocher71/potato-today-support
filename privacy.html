기록의 저장

오늘의 감자는 회원가입 없이 사용하는 개인 일기 앱입니다. 입력한 기분, 일기, 작은 순간, 수면 기록은 앱의 기기 저장소에 보관합니다. 이 기록을 개발자 서버로 전송하지 않으며, 광고·행동 분석·추적 SDK를 사용하지 않습니다.

백업과 외부 서비스

사용자가 내보내기를 선택하면 iOS 공유 기능으로 JSON 백업 파일을 저장하거나 공유할 수 있습니다. 내보낸 파일은 별도로 암호화하지 않습니다. 사용자가 직접 선택한 저장 위치 또는 공유 대상에는 해당 서비스의 정책이 적용됩니다. 가져오기는 사용자가 고른 JSON 백업 파일만 읽으며, 같은 날짜의 기존 기록을 덮어쓰지 않습니다. 가져오기·내보내기에 사용하는 임시 파일은 해당 작업이 끝나면 삭제합니다.

보관과 삭제

기록은 사용자가 지우거나 앱 저장소가 삭제될 때까지 기기에 보관됩니다. 오늘 기록은 수정 화면에서 삭제할 수 있고, 과거 기록은 읽기 전용입니다. iPhone에서 앱을 삭제하면 로컬 기록이 사라질 수 있습니다. 사용자가 별도로 보관한 백업 파일은 해당 저장 위치에서 직접 삭제해야 합니다. 운영체제의 기기 백업과 복원은 사용자의 시스템 설정 및 해당 서비스의 정책을 따릅니다.

선택적 알림

알림은 기본적으로 꺼져 있으며, 사용자가 직접 켤 때만 권한을 요청합니다. 밤 11시 알림은 기기에서 예약하고 푸시 토큰을 수집하거나 알림 서버로 보내지 않습니다. 알림 문구에 일기 내용은 포함하지 않습니다. 앱의 알림 설정 또는 iPhone 설정에서 끌 수 있습니다.

문의할 때 제공하는 정보

이메일 문의를 보내면 회신 주소와 문의에 포함한 내용을 문의 처리에 사용합니다. 일기 원문이나 전체 백업 파일은 보내지 않아도 됩니다. 문의 내용은 처리에 필요한 동안만 보관하며, 삭제 요청은 아래 연락처로 보낼 수 있습니다. 이메일 제공업체가 처리하는 정보에는 해당 업체의 정책이 적용됩니다.

이 웹사이트

이 지원 사이트는 별도 분석 도구나 광고 스크립트를 사용하지 않습니다. 이 사이트는 GitHub Pages에서 제공하며, GitHub가 접속 과정에서 처리하는 정보에는 GitHub 개인정보 정책이 적용됩니다. 앱의 일기 기록은 이 사이트에 전송되지 않습니다.
