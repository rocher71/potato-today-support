기록의 저장

오늘의 감자는 회원가입 없이 사용하는 개인 일기 앱입니다. 입력한 기분, 일기, 작은 순간, 수면 기록과 선택한 사진은 앱의 기기 저장소에 보관합니다. 이 기록을 개발자 서버로 전송하지 않으며, 광고·행동 분석·추적 SDK를 사용하지 않습니다.

백업과 외부 서비스

사용자가 내보내기를 선택하면 iOS 공유 기능으로 일기와 사진이 포함된 ZIP 백업 파일을 저장하거나 공유할 수 있습니다. 내보낸 파일은 별도로 암호화하지 않습니다. 사용자가 직접 선택한 저장 위치 또는 공유 대상에는 해당 서비스의 정책이 적용됩니다. 가져오기는 사용자가 고른 일기와 사진이 포함된 ZIP 백업 파일만 읽으며, 같은 날짜의 기존 기록을 덮어쓰지 않습니다. 가져오기·내보내기에 사용하는 임시 파일은 해당 작업이 끝나면 삭제합니다.

보관과 삭제

기록은 사용자가 지우거나 앱 저장소가 삭제될 때까지 기기에 보관됩니다. 오늘 기록은 수정 화면에서 삭제할 수 있고, 전날 기록도 기기 현지 시각 오전 5시 전까지 수정할 수 있습니다. 그 이후의 과거 기록은 읽기 전용입니다. iPhone에서 앱을 삭제하면 로컬 기록이 사라질 수 있습니다. 사용자가 별도로 보관한 백업 파일은 해당 저장 위치에서 직접 삭제해야 합니다. 운영체제의 기기 백업과 복원은 사용자의 시스템 설정 및 해당 서비스의 정책을 따릅니다.

선택적 알림

알림은 기본적으로 꺼져 있으며, 사용자가 직접 켤 때만 권한을 요청합니다. 밤 11시 알림은 기기에서 예약하고 푸시 토큰을 수집하거나 알림 서버로 보내지 않습니다. 알림 문구에 일기 내용은 포함하지 않습니다. 앱의 알림 설정 또는 iPhone 설정에서 끌 수 있습니다.

사진 선택

하루에 사진 한 장을 선택할 수 있습니다. 시스템 사진 선택기에서 고른 사진만 앱 저장소로 복사하며, 사진 보관함 전체를 읽거나 사진을 개발자에게 업로드하지 않습니다.

앱 내 제보

사용자가 제보를 직접 보내는 경우에만 작성한 내용, 선택한 회신 이메일, 앱 버전·빌드·운영체제·언어 정보를 Cloudflare와 Resend를 통해 개발자 이메일로 전달합니다. 접속 IP는 전송 제한에 사용하며 이메일 본문에는 포함하지 않습니다. 일기, 사진, 백업 파일은 자동으로 첨부하지 않습니다. 별도 제보 데이터베이스는 사용하지 않지만 문의는 개발자 메일함과 발송 서비스의 보관 정책에 따라 보관될 수 있습니다. 문의 처리와 답변에만 사용하며, 문의 정보 삭제는 아래 연락처로 요청할 수 있습니다. 직접 이메일로 문의할 때도 회신 주소와 문의 내용을 처리합니다.

앱 업데이트와 서비스 연결

앱은 Expo의 EAS Update를 통해 호환되는 앱 코드 업데이트를 확인하고 받을 수 있습니다. 이 과정에서 앱 설치별 무작위 식별자, 앱·운영체제 정보, IP 주소와 오류 등 서비스 운영 정보가 Expo에 전달될 수 있습니다. 이 정보는 업데이트 전달과 서비스 운영에 사용되며 일기와 사진은 포함하지 않습니다. App Store의 새 버전 확인 및 리뷰 기능에는 Apple 서비스가 사용됩니다. 인터넷 연결 시 서비스 제공업체가 IP 등 접속 정보를 처리할 수 있습니다.

서비스별 처리 사항은 Expo, Cloudflare, Resend 및 Apple의 개인정보 정책을 참고하세요.

이 웹사이트

이 지원 사이트는 별도 분석 도구나 광고 스크립트를 사용하지 않습니다. 이 사이트는 GitHub Pages에서 제공하며, GitHub가 접속 과정에서 처리하는 정보에는 GitHub 개인정보 정책이 적용됩니다. 앱의 일기 기록은 이 사이트에 전송되지 않습니다.
